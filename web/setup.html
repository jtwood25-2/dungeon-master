Table setup

Import each player's D&D Beyond sheet by pasting the link. No typing nine-digit ids into a microphone.

What each player has to do first

  1. Open their character on D&D Beyond.
  2. Click the gear / cog icon (top right of the sheet) → Character Settings.
  3. Set Character Privacy to Public. This is the only step that matters — the importer reads the public sheet, so a private one returns nothing.
  4. Send you the sheet URL: dndbeyond.com/characters/154114558
